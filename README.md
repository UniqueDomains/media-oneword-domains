## 🧱 Field summary

- `domain` — Fully qualified domain name.
- `status` — Current acquisition state for the domain in the public extract.
- `purchase_price` — Visible purchase price when available.
- `renewal_price` — Visible renewal price when available.
- `attractiveness` — Composite naming score used as a decision-support signal.
- `demand` — Relative buyer-pressure score when available.
- `length` — Character count without the TLD.
- `registrar` — Registrar name when known.
- `created_at` — Creation timestamp when known.
- `expires_at` — Expiry timestamp when known.

## ⚠️ Methodology and caveats

This set is centered on domains connected to the media theme, spanning a very wide TLD range and including many single-word terms. Examples in the selection include signal.ryukyu, culture.hamburg, virtual.new, writing.ryukyu, opinion.ryukyu, and content.ryukyu. For founders, the main question is whether the exact word and extension create a memorable, credible brand that feels easy to say and keep. For investors, the key test is whether the ask leaves room versus likely resale demand for that specific word-extension pairing. The median ask is $1,919, so pricing discipline matters when comparing stronger generic terms with more niche extension choices.
